📖 Acerca del proyecto
Zero Hunger es una plataforma digital diseñada para facilitar la conexión entre empresas donantes y organizaciones benéficas, con el objetivo de combatir el hambre y la inseguridad alimentaria. La aplicación permite a las empresas publicar y gestionar donaciones de alimentos u otros recursos, mientras que las organizaciones benéficas pueden explorar, solicitar y administrar las donaciones disponibles.

🎯 Objetivo
El principal objetivo de Zero Hunger es crear un ecosistema colaborativo donde las donaciones lleguen de manera eficiente a quienes más las necesitan, promoviendo la transparencia y la trazabilidad en el proceso de donación.

🧩 Funcionalidades clave
Empresas donantes:

Registro y gestión de donaciones (crear, editar, eliminar).

Seguimiento del estado de sus donaciones.

Organizaciones benéficas:

Exploración de donaciones disponibles.

Solicitud y gestión de donaciones recibidas.

Administradores:

Visualización de estadísticas generales:

Número de empresas donantes registradas.

Número de organizaciones benéficas activas.

Cantidad total de donaciones completadas.

Gestión de usuarios y supervisión de actividades dentro de la plataforma.

🌍 Impacto esperado
Al optimizar el proceso de donación y fomentar la colaboración entre el sector privado y las organizaciones sin fines de lucro, Zero Hunger aspira a contribuir significativamente en la lucha contra el hambre, asegurando que los recursos disponibles lleguen de manera oportuna y efectiva a las comunidades que más lo necesitan.
